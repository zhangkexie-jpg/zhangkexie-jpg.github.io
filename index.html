PERSONAL AI WORKFLOW

Hermes · 个人 AI 助理

Hermes 是供授权用户自行配置和使用的私人智能助理，用于整理信息、检索资料和完成经用户明确要求的 AI 分析与文档协同工作。此页面是应用说明，不提供公开账号注册或数据访问功能。

Google Drive 资料读取

经用户授予相应 OAuth 权限后，根据任务所指定的文件或文件夹只读读取内容，以进行提取、摘要和核对。当前协同读取通道使用 Google Drive 只读权限，不修改源文件。

邮件和自动化任务

在用户另外启用和授权的情况下，Hermes 可辅助处理邮件相关的查询和工作流；访问范围由 Google 授权页面显示的权限决定。不同设备或任务可具有不同的功能配置。

AI 复核与第三方服务

对于用户明确指定并允许送至外部模型的资料，工作流可在 GitHub Actions 环境内调用 Google Gemini API 进行分析，并在受限的私人 GitHub 任务中保存分析摘要。未经明确任务授权，不因用户访问本网站而读取其 Drive 或邮件。

重要：把文件提交给 Gemini API 进行处理与“仅在本地读取”不同。敏感材料是否允许这样处理，应由用户在每个任务中决定。

Google 数据使用说明

本应用以完成用户要求的助理功能为目的处理经授权的数据，不出售用于广告定位。如何访问、使用、共享、保留和删除 Google 用户数据，详见 公开隐私政策。

授权可以在 Google 账号的第三方连接设置中撤销；撤销后，依赖该权限的功能可能无法继续运行。

English overview

Hermes is a personally configured AI assistant for document retrieval, mail-related workflows where separately authorized, and user-directed AI reviews. With authorization, it may read selected Google Drive files. Only explicitly approved tasks transmit selected content to Gemini API. Review summaries may be retained in private GitHub Issues. See the Privacy Policy for access, use, retention, sharing and deletion details.
